<h2 align="center" id="my-mdp-project">🚗 Major Design Project</h2>

<div align="center">

### Smart Fog & Blind-Curve Collision Warning System

<img src="https://img.shields.io/badge/PROJECT-MDP-38BDF8?style=for-the-badge" alt="Major Design Project">
<img src="https://img.shields.io/badge/STATUS-IN%20PROGRESS-87CEEB?style=for-the-badge" alt="Project in progress">

</div>

**Problem:** Fog and blind curves can reduce visibility and make it difficult for drivers to detect approaching vehicles in time.

**Proposed solution:** A vehicular safety system designed to detect vehicles near blind curves, assess potential collision risks and communicate warnings to approaching drivers.

**My AI/ML contribution — planned work:**

- Explore computer vision for vehicle detection from camera feeds.
- Study YOLOv8 for vehicle detection and object tracking.
- Investigate how visual detection can contribute to collision-risk assessment.
- Evaluate suitable approaches as the project progresses.

**Proposed system components:** Camera-based detection, visibility sensing, ESP32-based warning logic, wireless communication and a receiver-side alert.

*This project is in progress. The model training, integration and testing are not presented as completed achievements.*
