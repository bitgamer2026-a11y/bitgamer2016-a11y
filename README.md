A reinforcement learning project focused on exploring autonomous F1-style driving by training a simulated driving agent using **Proximal Policy Optimization (PPO)**.

**Key goals**
- 🏁 Explore reinforcement learning for autonomous driving.
- 🧠 Study PPO as a policy optimisation algorithm.
- 🎮 Investigate reward functions for racing behaviour.
- 📈 Evaluate driving performance using simulation results.
